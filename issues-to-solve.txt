Issues to solve
===============

High priority
-------------

1. Fix inconsistent JWT cookie format.
   - Login writes a raw JWT cookie in src/server/user/userRoutes.js.
   - Token renewal writes "Bearer <token>" in src/server/config/autoRenewToken.js.
   - authenticateJWT expects a raw token from req.cookies.token.
   - Make all token writes use one consistent format, preferably the raw JWT.

2. Preserve JWT claims during token renewal.
   - Login signs { id, isAdmin }.
   - autoRenewToken signs only { id }.
   - Renewed admin users can lose isAdmin in /api/auth-status.

3. Fix password reset user lookup.
   - src/server/user/userRoutes.js assigns query rows to user.
   - Empty query results are arrays, so if (!user) does not catch no-match cases.
   - Check rows.length === 0 before updating the password.

4. Implement or remove /api/settings.
   - src/client/wrappers/SettingsWrapper.js fetches /api/settings.
   - src/server/settings/settingsRoutes.js currently exports an empty router.
   - Signup gating may redirect incorrectly until this endpoint exists.

Medium priority
---------------

5. Consolidate auth checks on the client.
   - appContext.js calls getToken() on app load.
   - PrivateWrapper.js calls /api/auth-status.
   - LoginWrapper.js calls /api/auth-status.
   - Use one auth source in context and have wrappers consume it.

6. Remove or merge duplicate client store code.
   - src/client/store/flux.js appears to duplicate logic now split into states.
   - src/client/store/combinedState.js is the one imported by appContext.js.
   - Delete flux.js if unused, or migrate any missing behavior.

7. Fix SettingsWrapper navigation side effects.
   - src/client/wrappers/SettingsWrapper.js calls navigate() during render.
   - Move redirect logic into useEffect or return <Navigate />.
   - Add loading and fetch-error states.

8. Rename database environment variables.
   - src/server/config/dbpool.js and sessionConfig.js use HOST, PORT, USER, PASSWORD, DATABASE.
   - These names can conflict with app port or OS variables.
   - Prefer DB_HOST, DB_PORT, DB_USER, DB_PASSWORD, DB_NAME.

9. Use mysql2/promise APIs consistently.
    - src/server/config/dbpool.js creates a promise pool but calls getConnection with a callback.
    - Use await pool.getConnection() in an async health check, or remove the startup connection check.

10. Remove sensitive console logging.
    - src/server/user/userRoutes.js logs JWTs, session objects, user IDs, and admin state.
    - Replace with structured safe logs, or remove.

11. Review secure cookie behavior in local development.
    - Login sets secure: true.
    - Secure cookies are not sent over plain HTTP.
    - Make cookie options environment-aware for local dev vs production.

Lower priority
--------------

12. Split large route handlers into services/controllers.
    - src/server/user/userRoutes.js mixes routing, SQL, auth, hashing, email, and logging.
    - Extract user data access, auth token handling, and email reset logic.

13. Add route-level input validation.
    - Login, signup, forgot-password, and reset-password accept raw request bodies.
    - Validate email and password fields before database calls.

14. Improve test isolation.
    - Current route tests fail with AggregateError, likely from database/session/email dependencies.
    - Mock MySQL, session store, JWT, and email transport for route unit tests.

15. Revisit Webpack bundle size.
    - Production build succeeds but warns that client.js exceeds recommended size.
    - Consider route-level code splitting and importing only needed MUI modules.

16. Clean generated output policy.
    - dist is generated by Webpack.
    - Confirm whether dist should be committed or ignored for the intended deployment flow.

17. Normalize naming and typos.
    - getEnviromentalVariables is misspelled.
    - Some routes/pages use placeholder names such as Teste.
    - Standardize names before the project grows.
